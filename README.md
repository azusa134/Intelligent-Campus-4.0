# 智慧校园 4.0

课表、跳蚤市场、校园跑腿、附近好店、校园墙，以及一个接入了「学校资源库」的 AI 助手——全部装在一个 `index.html` 里，双击就能跑。

**在线体验**：<https://azusa134.github.io/Intelligent-Campus-4.0/>
**演示账号**：`demo` / `123456`

---

## 这是什么

「智慧校园 4.0」是一个面向校园日常的 Web 原型：把课程表、闲置流转、跑腿互助、周边商家和校园动态收进同一个入口，再用积分体系把发布、交易、互助串起来。视觉上采用暖纸、墨与陶土的 **V3「Paper & Clay」** 主题，登录页是一块会随指针起伏的等距立方体网格。

项目为校园 AI 智能体创新应用大赛参赛原型，所有人物、商品与动态均为虚构演示数据。

## 功能一览

| 模块 | 能做什么 |
| --- | --- |
| 首页 | 今日课程、周课表（手动添加 / 粘贴文字智能导入）、校历月历、空教室与完整校历入口 |
| 跳蚤市场 | 发布闲置、最多 4 张实拍图、分类 / 搜索 / 排序、全屏详情转场、积分推流 |
| 校园跑腿 | 发布悬赏、接单、送达完成、按悬赏排序、推流曝光 |
| 校园墙 | 瀑布流动态、话题筛选、点赞 / 收藏 / 评论、匿名发布 |
| 附近好店 | 店铺列表、营业信息、促销与动态、商家入驻（演示） |
| 新生必看 | 4 篇新生指南 + 新生问答（提问、学长学姐解答得 5 积分） |
| 校园工具箱 | 空教室、失物招领、校园电话、完整校历 |
| 个人中心 | 积分明细、我的发布 / 接单 / 收藏、上课提醒、清除演示数据 |

**积分规则**：新人注册 +100，发布闲置 / 跑腿 +10，发帖 +5，完成交易 +20，完成跑腿 +15，解答新生提问 +5，邀请同学 +30；推流档位 30 积分 / 6 小时、80 / 24 小时、200 / 3 天。

## 小轻 AI × 学校资源库

右下角的悬浮球打开「小轻」，它不只查课表，还接入了 WorkBuddy 资料库里的「学校资源库」（人工智能学院，19 份材料 / 4 组）：

- **奖学金怎么申领**：申领三步、四档奖金与名额、智育 / 体育 / 德育 / 劳育门槛、6 项材料清单、报送地点与截止时间；
- **申请入党积极分子需要准备什么**：5 份材料按顺序（申请书 → 谈话记录 → 提交申请公示 → 推优登记表 → 确定积极分子公示），附模板里的时间线；
- **班级名额查询**：内置 72 个班级的 `[人数, 一等, 二等, 三等]`，问「软工本254 奖学金名额」会直接答 39 人、2 / 3 / 5 个名额；
- **资料库浏览**：AI 头部「资料库」可查看全部 19 份文件，点任意一条跳回资料库原文；回答末尾的来源标签同样可回溯。

资料库以只读快照内置在 `LIBRARY`，单文件原型不联网；资料库更新后替换快照并修改 `LIBRARY.synced` 即可。检索分三层：意图匹配（奖学金 / 入党 / 资料库）→ 结构化回答 → 中文二元组兜底检索（`libFind()`，重合度 ≥3 命中）。

## 技术实现

- **单文件**：`index.html` 内联全部 CSS / JS，无外部依赖、无构建步骤，双击即运行。
- **本地数据**：`localStorage`，键名 `limeCampusDB_v1`；`migrateDB()` 做旧数据平滑升级，不清空用户内容。
- **图片**：用户上传经 canvas 压缩到长边 1000px、JPEG 0.72、白底填充，以 dataURL 存在同一条记录里。
- **动效**：卡片统一 `card-flow` 入场；四类卡片点击后进入全屏详情并用 WAAPI 做封面 FLIP 转场；`prefers-reduced-motion` 下全部降级。
- **视觉**：V3 主题集中在 `<style>` 第 16 节；登录页 Canvas 等距立方体网格（正弦起伏、指针抬升、暖色聚光）；服务卡 3D 倾斜与磁性 AI 入口仅在精细指针下生效。
- **响应式**：断点 560 / 640 / 760 / 980 / 1080 / 1200 px，移动端底部为悬浮圆角 dock。

## 快速开始

```bash
# 方式一：直接双击 index.html
# 方式二：起一个本地静态服务
python3 -m http.server 8080
# 打开 http://localhost:8080
```

建议在浏览器标签页中直接打开。部分 IDE / 预览沙箱会禁用 `localStorage`，页面会提示「本机存储空间不足」，此时数据无法保存，换到浏览器打开即可。

## 数据与隐私

- 所有账号、商品、跑腿单与店铺均为演示数据，不涉及真实个人信息。
- 上传的照片只以 dataURL 存在本机 `localStorage`，不上传服务器。
- AI 资料库快照不包含学生姓名、邮箱、成绩单等个人信息，只保留制度、流程、名额与公开通知。
- 交易与跑腿提示线下当面确认，平台不提供真实支付；商家入驻为演示入口，仅在本地生效。

## 已知限制

- `localStorage` 每个源约 5MB，图片是主要占用（单张压缩后约 100–200KB）；写满时会提示，可在个人中心「清除演示数据」后重来。
- 小轻 AI 是本地规则引擎 + 资料库快照，不是在线大模型，不会实时请求资料库；要实时问答需要接后端或云服务。
- 推流、商家入驻、积分等为演示逻辑，不涉及真实结算。
