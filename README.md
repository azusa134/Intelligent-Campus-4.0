# 智慧校园 4.0

课表、跳蚤市场、校园跑腿、附近好店、校园墙，以及一个接入了「学校资源库」和在线大模型的 AI 助手——一个不用构建的静态站点，双击就能跑。

**在线体验**：<https://azusa134.github.io/Intelligent-Campus-4.0/>
**演示账号**：`demo` / `123456`

---

## 这是什么

「智慧校园 4.0」是一个面向校园日常的 Web 原型：把课程表、闲置流转、跑腿互助、周边商家和校园动态收进同一个入口，再用积分体系把发布、交易、互助串起来。新增 **GDIP 互动照片蒙赛克欢迎页**，38 张校园照片组成字母，悬停或轻触即可切换；应用内采用暖纸、墨与陶土的 **V3「Paper & Clay」** 主题，登录页是一块会随指针起伏的等距立方体网格。

项目为校园 AI 智能体创新应用大赛参赛原型，所有人物、商品与动态均为虚构演示数据。

## 小轻 AI × 学校资源库

右下角的悬浮球打开「小轻」，它不只查课表，还接入了 WorkBuddy 资料库里的「学校资源库」（人工智能学院，19 份材料 / 4 组）：

- **奖学金怎么申领**：申领三步、四档奖金与名额、智育 / 体育 / 德育 / 劳育门槛、6 项材料清单、报送地点与截止时间；
- **申请入党积极分子需要准备什么**：5 份材料按顺序（申请书 → 谈话记录 → 提交申请公示 → 推优登记表 → 确定积极分子公示），附模板里的时间线；
- **寒假社会实践有什么要求**：组队与指导教师、六类活动、材料规格（报告字数、视频时长与画幅、照片张数）、申报与总结节点、智慧校园 3.0 入口与保险要求；
- **班级名额查询**：内置 72 个班级的 `[人数, 一等, 二等, 三等]`，问「软工本254 奖学金名额」会直接答 39 人、2 / 3 / 5 个名额；
- **资料库浏览**：AI 头部「资料库」可查看全部 19 份文件，点任意一条跳回资料库原文；回答末尾的来源标签同样可回溯；
- **在线大模型**：本地答不上来的问题、以及「帮我写 / 翻译 / 润色 / 总结」类请求，会带上资料库摘要调用 **WorkBuddy 云服务的 LLM 接口**（免密钥、流式输出）；断网、域名未授权或额度不足时自动退回本地答案。

### 在线模型会不会消耗我的积分？

不会。分三层说清楚：

| 问题 | 结论 |
| --- | --- |
| 消耗谁的额度 | WorkBuddy LLM 接口按**应用创建者**的额度计费，也就是本项目部署者；额度用完时接口返回 `quota_` 类错误，小轻自动改用本地答案 |
| 访问者要付什么 | 不需要 WorkBuddy 账号、不需要 API Key，调用不消耗访问者本人账号的任何积分或额度 |
| 会不会扣页面里的「校园积分」 | 不会。那是 `localStorage` 里的演示积分，只用于发布 / 跑腿 / 推流；AI 问答不读也不写积分流水 |

口径写在代码里而不是只写在文档里：`js/ai/40-ai-config.js` 的 `AI_BILLING` 是唯一事实来源，AI 面板底部的常驻提示条与「在线模型与积分」说明层都读它，改口径只需改一处。

### 额度有多少？

接口不返回余额，只回传「这次花了多少」。实测样本（2026-10-30，DeepSeek-V4.1-Flash）：

| 项目 | 实测值 |
| --- | --- |
| 单次上下文 | 1353 字资料库摘要 → 990 输入 tokens |
| 单次输出 | 47–92 tokens（提示词限定 220 字以内） |
| 单次合计 | 约 1000–1100 tokens |
| 接口上报消耗 | 0.01–0.02 credits |

所以「还能问多少次」= 账号剩余额度 ÷ 单次消耗，具体数值在 **WorkBuddy 控制台 → 云服务用量** 查看。应用内不猜余额，只显示本次打开页面累计的调用次数、tokens 与 credits（诊断值，不等于账单）。

资料库以只读快照内置在 `LIBRARY`（`js/ai/41-ai-library.js`）；更新后替换快照并修改 `LIBRARY.synced` 即可。检索分三层：意图匹配（社会实践 / 奖学金 / 入党 / 资料库）→ 结构化回答 → 中文二元组兜底检索（`libFind()`，重合度 ≥3 命中）。在线调用由 `js/ai/44-ai-client.js`（WorkBuddy 接口封装）与 `js/ai/45-ai-service.js`（路由 / 上下文 / 降级）负责，只把资料库目录与命中要点作为上下文，不整库上传。

## 技术实现

- **多文件、零构建**：`index.html` + `assets/styles.css` + `js/{core,pages,ai,app}/*.js`，classic script 按顺序加载，不引入打包器；双击 `index.html` 仍可运行。
- **按职责分目录**：`core` 配置与数据层、`pages` 每个页面一个文件、`ai` 拆成配置 / 资料库 / 检索 / 本地问答 / 接口客户端 / 服务 / 面板、`app` 事件与视觉交互；单文件最大约 600 行。
- **缓存**：`index.html` 里所有 CSS / JS 带 `?v=YYYYMMDD`，发布时把版本号改一次，避免新增模块后浏览器还拿旧脚本。
- **缓存**：`index.html` 里所有 CSS / JS 带 `?v=YYYYMMDD`，发布时把版本号改一次，避免新增模块后浏览器还拿旧脚本。
- **本地数据**：`localStorage`，键名 `limeCampusDB_v1`；`migrateDB()` 做旧数据平滑升级，不清空用户内容。
- **在线能力**：WorkBuddy 云服务 LLM（`@tencent-ai/workbuddy-cloud-sdk`，免密钥），SDK 按需从 CDN 加载；`publicConfig` 放在 `js/core/00-config.js`。
- **图片**：用户上传经 canvas 压缩到长边 1000px、JPEG 0.72、白底填充，以 dataURL 存在同一条记录里。
- **动效**：卡片统一 `card-flow` 入场；四类卡片点击后进入全屏详情并用 WAAPI 做封面 FLIP 转场；`prefers-reduced-motion` 下全部降级。
- **视觉**：V3 主题集中在 `assets/styles.css` 第 16 节；登录页 Canvas 等距立方体网格（正弦起伏、指针抬升、暖色聚光）；服务卡 3D 倾斜与磁性 AI 入口仅在精细指针下生效。
- **响应式**：断点 560 / 640 / 760 / 980 / 1080 / 1200 px，移动端底部为悬浮圆角 dock。

## 快速开始

```bash
# 只想看界面与本地资料库回答：直接双击 index.html
# 需要在线模型（写文案 / 翻译 / 摘要）：必须走 http，任意端口都行
python3 -m http.server 8080
# 打开 http://localhost:8080
```

> **为什么双击打开时 AI 说「在线模型不可用」？**
> `file://` 页面的来源是 `null`，云服务按发布域名做 Origin 校验，浏览器会直接把请求拦成 `net::ERR_FAILED`（SDK 报 `gateway_network_error` / `Failed to fetch`）。这不是额度问题，也不是代码 bug：换成本地静态服务或已发布域名就恢复正常。此时 AI 面板会显示「本地模式」，头部与底部提示条都会标出来，资料库问答照常可用。

建议在浏览器标签页中直接打开。部分 IDE / 预览沙箱会禁用 `localStorage`，页面会提示「本机存储空间不足」，此时数据无法保存，换到浏览器打开即可。

在线模型需要联网：第一次提问会从 CDN 加载 SDK（约 1–2 秒），之后复用连接。断网、域名未授权或额度用尽时，AI 会自动退回本地资料库答案，并说明原因。

## 数据与隐私

- 所有账号、商品、跑腿单与店铺均为演示数据，不涉及真实个人信息。
- 上传的照片只以 dataURL 存在本机 `localStorage`，不上传服务器。
- AI 资料库快照不包含学生姓名、邮箱、成绩单等个人信息，只保留制度、流程、名额与公开通知。
- 交易与跑腿提示线下当面确认，平台不提供真实支付；商家入驻为演示入口，仅在本地生效。

## 已知限制

- `localStorage` 每个源约 5MB，图片是主要占用（单张压缩后约 100–200KB）；写满时会提示，可在个人中心「清除演示数据」后重来。
- 小轻 AI 采用「本地规则 + 在线模型」混合：高频政策问题走本地模板，保证快且不编造；其余问题走云服务大模型，会消耗应用创建者的 WorkBuddy LLM 额度（SDK 不暴露余额，控制台可查）。
- 在线模型依赖 CDN 与云服务网络；不可用时会降级，功能不中断。
- 推流、商家入驻、积分等为演示逻辑，不涉及真实结算。
